# Gym Log

筋トレ用の記録アプリ(PWA)。スマホで、マシンごとの重量・回数の記録と、セット間のインターバル計測ができます。

- 記録はスマホのブラウザ内(localStorage)に保存されます。サーバーは使いません。
- 一度開けばオフラインでも動きます(Service Worker)。
- HTML / CSS / JavaScript だけで、ビルド不要です。

## 機能

| 画面 | できること |
|---|---|
| 記録 | マシンを選び、重量と回数を入れて「セットを記録」。前回の記録と今日のセットを表示 |
| 履歴 | 日付ごと、マシンごとの記録一覧。セットの削除 |
| 管理 | マシンの追加・名前変更・削除、設定、バックアップ |
| タイマー(画面下) | 1分 / 1分30秒 / 2分 / 3分。記録すると自動で開始(設定でオフ可)。終了時に音とバイブ、実行中は画面スリープを抑止 |

## 公開手順(GitHub Pages)

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 数分後、`https://porygon-works.github.io/gym-log/` で公開される

GitHub のユーザー名(またはリポジトリ名)を変えると公開URLも変わります。その場合は、Firebase コンソールの **Authentication → Settings → 承認済みドメイン** に新しいドメイン(例: `porygon-works.github.io`)を追加しないと、Google ログインができません。ホーム画面のアイコンも、新しいURLから追加し直してください。

## スマホのホーム画面に追加する

- **iPhone (Safari)**: 公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: 公開URLを開く → メニュー(︙) → 「ホーム画面に追加」または「アプリをインストール」

## データの扱い

- 記録はその端末のブラウザにだけ残ります。ブラウザのデータを消すと記録も消えます。
- **管理 → 書き出し** で JSON ファイルに保存、**読み込み** で復元できます。
- **管理 → Claude用にコピー** で、記録をテキストとしてコピーできます。Claude に貼り付けて、フォームの分析や次回の重量の相談に使えます。

## ローカルで動かす

Service Worker は `file://` では動かないため、簡易サーバー経由で開きます。

```
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。

## ファイルを更新したとき

`sw.js` の `CACHE` の番号(例: `gymlog-v1` → `gymlog-v2`)を上げてください。上げないと、スマホに古い版が残ることがあります。
